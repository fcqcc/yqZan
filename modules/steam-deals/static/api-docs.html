🔧 使用示例

1. 注册 API Key

# 在下方表单输入邮箱 → 点击免费注册

# 方式二：命令行

2. 获取每日 Top 10 折扣

curl -H "X-API-Key: sk-xxxxxxxxxxxxxxxx" \
  https://yqzan.cn/steam/api/top?limit=10

3. 搜索特定游戏

curl -H "X-API-Key: sk-xxxxxxxxxxxxxxxx" \
  "https://yqzan.cn/steam/api/search?q=Hades&min_discount=50&sort_by=discount"

4. 获取今日统计

curl -H "X-API-Key: sk-xxxxxxxxxxxxxxxx" \
  https://yqzan.cn/steam/api/stats

Python 示例

import requests

API_KEY = "sk-xxxxxxxxxxxxxxxx"
BASE = "https://yqzan.cn/steam"

r = requests.get(f"{BASE}/api/top?limit=10",
    headers={"X-API-Key": API_KEY})

print(f"剩余调用: {r.headers['X-RateLimit-Remaining']}")
for deal in r.json()["deals"]:
    print(f"{deal['name']} -{deal['discount_percent']}% ¥{deal['final_price']}")
